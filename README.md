# LoRA Dataset Tagger Pro

基于 Vite + React + TypeScript + Tailwind CDN 的本地 LoRA 训练集标注工具。

## 功能概览

- 批量导入训练图片。
- 编辑 Danbooru 风格标签，支持跨图片冻结字段。
- 支持基础打标与进阶打标两种模式。
- 调用 Gemini 或 OpenAI 兼容接口自动生成标注。
- 在设置面板中自定义 API 密钥、基础反推提示词与进阶反推提示词。
- 导出单张 `.txt` 标注文件或整个数据集 ZIP 包。
- 对超大图片进行缩放，实时预览并显示原始尺寸角标。
- 全屏弹窗查看最终标注文本，支持一键复制。

## 本地运行

**环境要求：** Node.js

1. 安装依赖：`npm install`
2. 如需 AI 自动标注，在 [.env.local](.env.local) 中配置 `GEMINI_API_KEY`
3. 启动开发服务器：`npm run dev`
4. 浏览器访问 `http://localhost:3000/`

OpenAI 兼容接口的自定义设置以及反向提示词覆盖值会在浏览器本地存储中保存（通过设置面板操作）。注意：不要将 API 密钥或本地生成的配置提交到代码仓库。

## 使用教程

### 1. 导入图片

点击左上角导入按钮选择一张或多张图片。导入后，左侧列表会显示缩略图，点击缩略图可切换当前编辑图片。

本地快速测试可使用示例图片：

```text
dataset/test_only/305895.jpg
```

### 2. 配置 AI 打标

打开 `Settings`：

- `API Settings`：配置 OpenAI 兼容接口的 `Base URL`、`API Key` 和 `Model`。关闭自定义 API 时，应用会使用 `.env.local` 中的 `GEMINI_API_KEY`。
- `Reverse Prompt Settings`：配置基础打标提示词和进阶打标提示词。点击 `Restore Default` 可恢复内置默认值，保存后生效。

常见 OpenAI 兼容地址格式：

```text
https://example.com/v1
```

不要把 API Key 写入 README、截图、提交记录或公开 issue。

### 3. 基础打标

选择 `Basic` 模式后，点击 `AI Caption`。成功后，工具会把结果拆成角色、画风、服装、表情、动作、背景等字段。

你可以手动编辑任意字段；最终导出的文本会自动合并为 Danbooru 风格逗号标签。字段旁的锁定按钮可让该字段在切换图片时保持不变，适合批量处理同一角色或同一画风的数据集。

### 4. 进阶打标

选择 `Advanced` 模式后，点击 `AI Caption`。进阶模式会生成单个结构化文本，包含 XML 风格标签和 `caption:` 长描述。

进阶模式适合需要保留角色框、角色分组、场景长描述或 Newbie 风格训练描述的图片。你可以直接编辑文本框内容，最终预览和导出会使用这段文本。

### 5. 预览与导出

右侧 `Final Formatted Output` 会实时显示当前图片最终标注。

- 点击复制按钮可复制当前标注。
- 点击全屏按钮可打开完整预览弹窗。
- 点击单张导出可下载当前图片对应的 `.txt`。
- 点击批量 ZIP 导出可把图片与标注一起打包。

### 6. 调整图片尺寸

点击 `Resize` 打开缩放面板，设置最长边尺寸后应用。预览图上会显示原始尺寸角标，方便确认图片是否已被压缩到训练需要的大小。
